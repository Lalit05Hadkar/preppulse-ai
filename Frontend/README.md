# PrepPulse AI — Frontend Client

The official web application interface for **PrepPulse AI — Intelligent Career &amp; Interview Readiness Engine**.

## Tech Stack
- **Framework:** React 19 + Vite 7
- **Routing:** React Router 7
- **Styling:** Vanilla SCSS (Modular &amp; Glassmorphic)
- **HTTP Client:** Axios (Cookie-based session credentials)

## Scripts
- `npm run dev` — Starts local development server on `http://localhost:5173`
- `npm run build` — Bundles production assets into `/dist`
- `npm run preview` — Locally previews production build
